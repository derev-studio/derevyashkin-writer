## 🚀 Как загрузить сайт на хостинг

### Вариант 1: Бесплатный хостинг GitHub Pages
1. Создайте аккаунт на [GitHub](https://github.com)
2. Создайте новый репозиторий с именем `derevyashkin-writer`
3. Загрузите файлы:
   - `index.html`
   - `README.md` (этот файл)
4. В настройках репозитория → Pages выберите `main` ветку и `root` папку
5. Сайт будет доступен по адресу: `https://имяпользователя.github.io/derevyashkin-writer`

### Вариант 2: Платный хостинг (рекомендуется)
**Популярные варианты:**
- Timeweb (Россия) - от 99 руб/мес
- Beget (Россия) - от 119 руб/мес  
- Hostinger (международный) - от 2.99$/мес

**Инструкция для любого хостинга:**
1. Купите хостинг и домен (например: `derevyashkin-writer.ru`)
2. Зайдите в панель управления хостингом
3. Найдите "Файловый менеджер" или "Менеджер файлов"
4. Загрузите файл `index.html` в корневую папку (`public_html` или `www`)
5. Сайт станет доступен по вашему домену

### Вариант 3: Netlify (бесплатный)
1. Зайдите на [Netlify](https://netlify.com)
2. Нажмите "Add new site" → "Deploy manually"
3. Перетащите файл `index.html` в окно загрузки
4. Получите случайный адрес или подключите свой домен

## 🔧 Настройки после загрузки

### Замена ссылок
В файле `index.html` найдите и замените:
- `https://ko-fi.com/X8X71WAGRF` → ваша реальная ссылка Ko-fi
- Email и контакты при необходимости

### Добавление новых книг
В JavaScript части файла найдите массив `const B=[...]` и добавьте новые книги по формату:
```javascript
{t:"Название книги", g:"Жанр", r:5.0, v:1, f:true, c:"код_книги", u:"url-книги", d:"Описание книги"}
```

### Аналитика (по желанию)
Добавьте Google Analytics или Яндекс.Метрику перед тегом `</head>` для отслеживания посещений.
